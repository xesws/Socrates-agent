# v0.11.0 — 不叫「师傅」，也不叫「点读笔」，直接叫苏格拉底

> 读者的原话：「现在的 UI 描述有点太中二了，上面写着『点读笔』，对话过程中
> 又写的是『师傅』。」日期：2026-08-21。

## 两个名字，三层深度

界面上是「点读笔」，对话里自称「师傅」——两个名字打架，而且都中二。
全仓 78 处。但它们不在同一层，处理方式也不一样：

| 层 | 例子 | 不改的后果 |
| --- | --- | --- |
| **模型的自我认知** | `SYSTEM_PROMPT` 的「你是坐在读者旁边的师傅」 | **光改界面没用**——模型照样在回复里自称师傅。读者那张截图里就是「不读就猜，那是江湖骗子干的事，师傅不干」 |
| 界面文案 | `appName` / 气泡标签 / 状态行 | 眼睛直接看到 |
| 注释与测试 | 「书架印出师傅读不到的路径」 | 代码和产品长期对不上 |

所以改动从 prompt 开始，不是从 `zh.ts` 开始。

## 顺手修掉两处**本来就写错**的

这两处如果照着「师傅→苏格拉底」机械替换，会得到更糟的结果：

| 位置 | 原文 | 问题 | 改成 |
| --- | --- | --- | --- |
| `tutor.py` 拒绝编辑时的工具结果 | 「师傅不允许这次编辑」 | 拒绝的是**读者**点的那一下。换成「苏格拉底不允许」＝让模型以为是它自己否掉的 | 「读者不允许这次编辑」 |
| `agent/registry.py` 的 edit_file 说明 | 「调用后会等师傅审批」 | 审批的也是读者。而模型自己就是那个角色，等于告诉它「等你自己批」 | 「调用后会等读者审批」 |

## 语气那一行不是简单换名

原文：`语气：师傅带实习生，口语，短句，别客服腔。`

「师傅带实习生」在做真活——它设定的是**语域**（口语、短句、不客服腔），
不是名字。换成「苏格拉底带实习生」既怪又没了那个意思。改成：

```
语气：像坐在旁边的人在说话，口语，短句，别客服腔。
```

`en.ts` 里那句「语气对齐中文表：师傅带实习生……」是在**引用**这句话，
所以跟着改，否则它指向一句已经不存在的话。

## 插件显示名也改了，但 `id` 没动

`manifest.name` 原来是 `Socrates Pen` —— 字面就是「苏格拉底点读笔」，
而且 Obsidian 拿它当**命令前缀**：中文界面里显示成
「Socrates Pen: 用当前选区提问」。所以它其实是读者抱怨的那个界面的一部分。

改成 `Socrates`。**`id: "socrates-pen"` 保持不变**——那是插件目录名
（`.obsidian/plugins/socrates-pen`），改了读者的设置会认不回来。

顺带修了八处**指路文案**：「请到设置 → Socrates Pen 填写 API Key」——
插件改名之后这句会把读者指到一个不存在的名字上。

读者拍板英文一并改，所以 `appName` / 气泡标签也从 `Socrates Pen` / `Pen`
变成 `Socrates`。

## 不动的

- **`SWE-Agent通关手册v2.md`**（124 处）：那是读者自己的教材内容，不是我们的界面。
- **`docs/`**：历史设计文档是记录，改了就是篡改当时的事实。

## 验证

真跑一次，故意问「你是谁？你怎么称呼自己？」——模型以前会自称师傅：

```
状态行：苏格拉底在想…
回复：我是苏格拉底——名义上叫这个，实际就是坐你旁边陪读的那个人。……
自称「师傅」: False | 出现「点读笔」: False | 出现「苏格拉底」: True
```
