# v0.2.1 — Obsidian 插件对抗审查（三路 Kimi K3）

> 审查对象：`obsidian/` v0.2.0（`3213bf4`）+ sidecar。日期：2026-08-18。
> 三路：加载会不会挂 / 与 sidecar 逻辑对不对 / 进库之后环境做不到什么。
> 父代理对照 `obsidian.d.ts` 1.13.1 抽查过 `MarkdownRenderer.render` 签名。

---

## 总判

**插件能加载，核心对话能跑。** CJS 打包、externals、`manifest.id` 对文件夹、`isDesktopOnly`、`FileSystemAdapter` 守卫、`registerView` / `getRightLeaf`、类型-only 循环引用，都没有「一启用就白屏」的硬伤。

真正要修的是移植时抄漏的逻辑，以及几处在 Obsidian 里必然降级、不要当成实现漏洞的事实。

## A. 会不会加载失败

| 项 | 结论 |
|---|---|
| esbuild cjs + `require("obsidian")` | 对 |
| `manifest.json` / `main.js` / `styles.css` 三件套 | 测试库已打出 |
| `MarkdownRenderer.render(app, md, el, path, component)` | 与 1.13.1 类型一致 |
| ItemView 生命周期 | 对 |
| 社区插件列表 | 测试库已启用 `socrates-pen` + `hot-reload` |

**没有加载级 blocker。**

未在真机抓包、仍可能让「功能全挂」的网络假设：

1. Origin 是否永远是 `app://obsidian.md`（sidecar 已放行，curl 预检过；换版要再看 DevTools）。
2. 较新 Chromium 的 Private Network Access 预检（`app://` → `127.0.0.1`）。现在多数 Obsidian 还放行。

这两条症状都会被误报成「sidecar 未启动」。

## B. 逻辑问题（代码该修）

### 必要修复（本轮 Kimi 实现）

**H1 — 写回芯片永远灰（高）**  
服务端 `writeback.enabled` 恒为 false。网页用 `substantive` 覆盖打开。插件写成 `substantive && c.enabled`，永远 false。`doPropose` / 预览框整条死路。  
修法：与网页一致，`writeback` 只看 `substantive`。本版仍不提供 apply。

**H2 — 设置/README 不提 `PEN_ALLOW_ROOTS`（高，文档）**  
vault 笔记不在仓库根就会 import 400。测试库的 `.env` 已写过，外人第一次必撞。  
修法：设置页说明 + `obsidian/README.md`。

**M1 — 「新开会话」绑错文件（中）**  
session 按 `this.handbookId` 建，`saveData` 却写 `getActiveFile()`。侧栏点击时焦点常在别的笔记，旧笔记下次框选会把刚丢掉的记忆续回来。  
修法：视图里记住捕获到的 `TFile` / path，新会话绑那条。

**M2 — `handbook_id` 先拼再 `slice(0, 80)`（中）**  
超长文件名可能砍掉哈希后缀，撞 id；`register` 不校验路径，后登记盖掉先登记。  
修法：截 slug、保留完整哈希；id 仍符合 `_SAFE_ID`。

**M4 — `paintLog` 每 token 全量异步重绘竞态（中/高观感）**  
`empty()` + 对每条 `await MarkdownRenderer.render`，两次调用会交错，中途重复/乱序。`finally` 会自愈。  
修法：串行化（generation 或锁），流式只更新最后一条助手气泡，done 时再整表画一次。

**L3 — 健康检查把一切失败都说成「sidecar 未启动」（低）**  
CORS / 500 也会显示未启动。  
修法：区分网络失败文案，不要用 `startsWith("sidecar 未启动")` 当门闩。

## 本轮修复范围（给实现 agent）

只改插件（必要时一行 sidecar 测试）。**不**做：阅读模式 DOM 选区、浮窗、apply、Q3、MathJax 括号、社区送审。

验收：

- 有实质回答后「写回」芯片可点，propose 出 diff，仍无 apply。
- 新开会话绑的是捕获的那篇笔记。
- 长文件名 handbook_id 仍带哈希。
- 流式出字不交错复制气泡。
- 设置页 / README 写明 `PEN_ALLOW_ROOTS`。
- `pytest` 全绿；`cd obsidian && npx tsc --noEmit && npm run build`。
