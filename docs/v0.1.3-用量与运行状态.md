# v0.1.3 — 上下文用量 + 提问中的运行状态

> 对照点读笔两处小瑕疵。日期：2026-08-18。
> 不改会话模型、不改写回、不改手册。

## 做什么

1. `done.usage` 用**最后一次** LLM 调用的 `prompt_tokens` 作为 `context_tokens`（此刻喂进去的上下文），`completion_tokens` 用最后一枪。界面：`上下文 N · 回复 M`。
2. 安静缺口先吐 `status` SSE；前端一进 `send` 就显示「师傅在想…」，翻文件 / 出字时换文案。写回/回滚共用状态行。

## 不做

真流式、窗口分母、usage 落盘、按 token 截断历史。
