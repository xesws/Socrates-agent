# v0.2.6 — 侧栏对话三种角色分清，气泡收紧

> 对照真机截图：芯片问答已通，但 user / tool / assistant 几乎同一灰底。日期：2026-08-20。
> 性质：插件 UI。不改 sidecar、不改 SSE、不 apply。

## 做什么

侧栏日志按师傅带实习生的工作台来画：

- **你**：右对齐短气泡，纯文本。
- **翻手册**：不是气泡，一行等宽状态（成功/拒绝 · 文件名）。
- **点读笔**：左强调线，里面才是 Markdown。

助手气泡内标题/段落/列表/表格 margin 收紧；摘录最多两行。颜色只用库主题 CSS 变量。

## 不做什么

不把 `web/` 的 desk/brass/phosphor 搬进插件。工具行刷新后仍不落盘（sidecar `ui_messages` 本来就不存 tool）。
