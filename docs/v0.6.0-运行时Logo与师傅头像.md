# v0.6.0 — 运行时 Logo 与师傅头像

> 打开侧栏第一眼是一行灰色调试字符串，没有品牌感。做一套字符画：开屏的苏格拉底肖像 + 3D 字标，以及每条师傅回复前的微缩头像。日期：2026-08-20。

## 肖像不是手绘的，是照片转的

先手绘过三版线条卡通，都太业余。改成把参考画像做**密度映射**：按亮度把像素映到 8 级密度阶 `" .:sA3G&@"`（由稀到密）。

关键参数（换图重做时照这个来）：

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 密度阶 | 8 级 | 实测比 24 级、12 级都清楚。级数多了反而灰糊一片，缺明暗对比 |
| gamma | 0.95 | 提亮中间调，让脸部结构出来 |
| contrast | 2.4 | 弱对比时整幅画是一团灰 |
| floor | 0.17 | **低于此值直接输出空格**。没有它，暗背景会变成满屏 `.` 噪点，肖像浮不出来 |
| 纵横补偿 | ×0.5 | 等宽字符高约是宽的 1.67 倍，纵向采样率不补偿脸会被拉长 |

四份资产：肖像 76×51（宽档）/ 46×31（窄档），字标 84×5 / 62×4，头像 14×11。

字标 `SOCRATES` 用**半块编码**（`▀▄█`）：一个文本行承载两个像素行，垂直分辨率翻倍而列数不变——这是在窄侧栏的列宽预算里做出可读字形的唯一办法。

## 深浅主题共用一份画

一开始以为浅色主题要一份反转资产，实测**不用**：形状信息在字符密度里，与字色无关。深色主题下浅色字符在暗底上把脸提亮，浅色主题下深色字符在白底上把脸压暗，两边都是正确的肖像。省掉一半资产。

## 字号是反解出来的，不是缩放出来的

```
自然宽度 = 列数 × 字号 × 字宽比   =>   字号 = 可用宽 / (列数 × 字宽比)
```

```css
font-size: clamp(4px, calc(100cqi / (var(--sp-cols) * var(--sp-adv, 0.6))), var(--sp-art-max, 13px));
```

`--sp-cols` 由 `art()` 在模块加载时算出（禁止手写），`--sp-adv` 是实测的字宽比（SF Mono 0.6 / Menlo 0.6023 / Consolas 0.55），用 64 个 `"0"` 在 100px 字号下离屏量一次，误差摊薄到 1e-4，量不到时回退 0.6。挂在 `onResize()` 与 `workspace.on("css-change")` 上重测，两者都由框架自动清理。

**没有用 `transform: scale()`**：它不参与布局，缩放后外层盒仍占原高度，得靠 JS 追平；而且会把 `text-shadow` 的厚度一起缩掉。反解字号则让布局高度天然跟着走，零 ResizeObserver。

宽窄两档都进 DOM，由 `@container (min-width: 330px)` 挑一档显示——比在 JS 里测宽度选资产少一条生命周期。

## 中文标语

「苏格拉底学习法」本版用真字形 + `em` 单位分层 `text-shadow` 做挤出。

> **v0.7.1 已推翻这一节**：字标改用与肖像同一套密度阶之后，3D 挤出跟密度字符的手工感打架，中文标语也不再做任何渲染，直接是一行等宽文字。理由见 `docs/v0.7.1`。

## 师傅头像

每条助手气泡左侧挂一个 14×11 的微缩肖像，`font-size: 4px`（约 34×44px）。**4px 是这幅画的清晰度下限**，3px 实测只剩一团灰。

整幅头像用**一个** div + `white-space: pre` 承载，不逐行拆：它没有逐行动画，而对话里可能有几十条助手消息，逐行拆会平白多出几百个节点。

`.sp-turn.is-assistant` 因此改成横向 flex（头像 + `.sp-turn-main`）。用户气泡与工具行不动，`docs/v0.2.6` 定的三层分层仍然成立。

## 显示时机

放在 `paintLog()` 的 `msgs.length === 0` 分支，两档：

- 没抓选区 → `hero`：肖像 + 字标 + 标语
- 抓了选区还没提问 → `mini`：只留字标，把高度让给引文和芯片
- 有任何消息 → 不渲染

消失是自动的，不需要新状态字段。「新开会话」清空 `msgs` 会让它回来。用 `splashLevel` 差分，只在档位变化时播入场动画，否则空态被重画几次就闪几次。

## 编辑规约（写进 logo.ts 文件头）

1. 一律 `String.raw`；因此画里**禁止反引号**（raw 里无法转义），一律用 `'`。
2. 禁止 `${`。
3. 只用 7-bit ASCII 或 U+2580–259F 方块元素。**不要用 `●` `▽` `─` 这类 East-Asian-Width = Ambiguous 的字符**：用户等宽字体栈一旦落到中文字体，它们占两列，整幅画会散。
4. `lintArt()` 在模块加载时对全部资产跑一次自检，违规会在控制台指出具体哪幅哪行——否则错位是静默的。

## 无障碍

外层 `role="img"` + `aria-label`，读屏念一次品牌名，后代自动 presentational，不会逐字念字符画。`user-select: none` 防误选。入场动画（逐行浮现 → 字标擦出 → 标语淡入）全部包在 `@media (prefers-reduced-motion: reduce)` 的关闭规则里。

已核实 `selection.ts` 会排除 `.socrates-pen` 内的选区，Logo 不会污染选区抓取。

## 注意

`esbuild.config.mjs` 的 `copyStatics()` 只在启动时跑一次，`context.watch()` 只监听 TS——`npm run dev` 期间改 `styles.css` 不会同步到测试库，必须重启。
