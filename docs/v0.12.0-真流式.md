# v0.12.0 — 真流式：读者不用再对着空屏幕干等 11 秒

> 读者：「思考过程中我们什么都看不到，只能看到下面显示一行『苏格拉底正在想』。
> 看有没有办法把当前 download 了多少 token 的过程呈现出来。」
> 日期：2026-08-21。

## 实测数据决定了方案

真实规模（prompt 约 3.2k token、带工具 schema）：

| | |
| --- | --- |
| 第一个分片（推理内容） | **1.3s** |
| 第一个**正文**分片 | **14.5s** ← 读者干瞪眼的就是这一段 |
| 全部结束 | 20.4s |
| 推理分片 / 正文分片 | 1633 / 850 |

两个结论：

1. **SDK 完全支持**，`stream_options={"include_usage": True}` 也能在末片拿到
   usage。所以「退而求其次做个假动画」这条不用走。
2. **光靠正文流还不够**——正文要十几秒才开始。但 DeepSeek 的
   `delta.reasoning_content` **1.3 秒就开始流**。「它在动」这件事 1.3 秒就
   能给读者看，而且给的是**真数**，不是假动画：真卡死了那个数就不跳了。

## 改之前，吐字是假的

`llm_create_kwargs` 里 `stream` 写死 `False`，整段回复到齐之后由
`_finish_text` 按 48 字符切成 token 事件吐出去。读者看到的「逐字」是
**回复早就写完之后**的一段表演，真正的等待全在那之前。

## 改法

`_create` 变成生成器，用 `yield from` 拿返回值——`_agent_loop` 的结构不用动：

```python
reply = yield from _create(with_tools=True)
```

流里三样东西分开走：

| delta 字段 | 处理 |
| --- | --- |
| `reasoning_content` | **只计数**，报 `{"type":"think","chars":N}` 让状态行跳数字 |
| `content` | 转成 `token` 事件——这才是真吐字 |
| `tool_calls` | 按 `index` 把 `arguments` 的碎片拼回去 |

末片的 `usage` 照旧喂给 meter。

### 三个非踩不可的坑

**① 工具调用分片。** `arguments` 是一片一片来的，`id` 和 `name` 只在第一片
出现，而且**分片不保证按 index 有序**。拼错一个字节 `json.loads` 就炸、
整轮对话失败。测试里的假分片故意切得碎且不对齐（正文 7 字一片、参数 5 字
一片）——对齐的假分片测不出这个。

**② 芯片块不能吐给读者。** 它是给界面剥的，而流式下 `<!--pen:chips` 这个
记号本身会被切碎。所以只吐到记号之前，尾巴留 `len(marker)-1` 不吐，
等下一片来了再说；**流完必须冲一次**，否则每条回复都缺一截尾巴
（没有芯片块时那个保守切法会一直压着最后十几个字）。

**③ 收尾不能再吐一遍。** 前端是 `acc += text` 累加的，`_finish_text` 原样
再吐一次读者会看到两份。加了 `streamed=True` 跳过。

顺带：v0.11.1 手工把 `reply.content` 吐出去那段可以删了——真流式下那段话
在收分片的当口就已经吐过了。

## 范围：只有主对话线改

后台深挖、写回折叠块、诊断评语**都不动**——没人盯着它们看，流式只会给那三条
线增加复杂度和失败面。

## 只报数，不显示推理正文

1633 个分片塞进窄侧栏是灾难，而且读者要的是「没卡住」，不是「让我读它的草稿」。
状态行显示 `苏格拉底在想… 3.6k 字`，正文一到就让位给「在写…」。

## 效果（真跑）

```
  1.1s  ← 读者第一次看到东西（以前是一片空白）
  2.5s  苏格拉底在想… 730 字
  5.0s  苏格拉底在想… 1886 字
  7.5s  苏格拉底在想… 2790 字
 10.0s  苏格拉底在想… 3575 字
 11.0s  ← 正文开始逐字出现
 17.6s  done
```

**干瞪眼从 11 秒降到 1.1 秒**，而且中间那个数一直在跳。

## 代价

25 处用假 client 的测试要改成吐分片，集中在 `test_agent._patch_script`
一个 helper 里（另有两处各自写了假 client 的也一并复用它）。机械改动，
一次改完 27 条红降到 0。
