# v0.1.5 — 对照 Kimi：变成 Obsidian 插件还差什么

> 依据 Kimi K3 交叉审查（当前功能正确性 + Obsidian 映射）与此后落地的 v0.1.1–v0.1.4。
> 性质：**对照与开工约定**，本文不改产品代码。日期：2026-08-18。

---

## 一句话

不要把整个点读笔搬进插件。要做的是 **薄插件（UI）+ 现有 `python -m pen` sidecar（脑子 / 写盘 / 密钥）**。  
第一版开在本仓 `obsidian/`，**现在不要另开 repo**。

---

## 当时拍板、现在也不该改

| 路 | 为什么不行 |
|---|---|
| 整个 `pen/` 用 TypeScript 重写成插件 | 钥匙进 vault（会随 Sync 走）；`read_file` 要读手册目录外的对照文件；`gitops` 要 subprocess；现有 pytest 和「别动 insert 流水线」作废 |
| iframe 嵌现在的 Vite | 还要再开 5173；选区仍是 iframe 里的 DOM 戳；和编辑器零集成 |
| 插件直接打 DeepSeek，sidecar 只负责写盘 | 会话和工具循环在 `tutor.py`；钥匙又进了库 |
| 改用别人的 Local REST API 插件 | 控制反了；50 轮 SSE 工具循环塞不进「一次 vault 请求」 |

正确形状：

```text
Obsidian（桌面，isDesktopOnly）
  socrates-pen 插件
    选区（CM6）· PenView · DiagnoseView · Settings
    saveData：sidecar URL、按笔记路径的 session_id
              │
              │  HTTP + SSE → http://127.0.0.1:8765/v1/*
              ▼
python -m pen
  DeepSeek · 索引 · 写回 / 快照 / gitops · .pen/
  密钥只活在 sidecar 的 .env
```

官方插件格式就是库里三件套：

```text
<Vault>/.obsidian/plugins/<plugin-id>/
  manifest.json
  main.js
  styles.css
```

第一版必须 `isDesktopOnly: true`。安装走手动拷贝或 BRAT。**先不要送社区审核**（本机 8765、库外 `.pen/`、可选 git，审核会很痛）。

## 对照现在：已经有的 vs 还缺的

Q1 之后本仓已经补过、对插件有用的：

| 版本 | 对插件的意义 |
|---|---|
| Q1 | 会话落盘、`GET /v1/sessions/{id}`、提案落盘、search 200 诚实拒绝 |
| v0.1.1 | import 只接受允许根下的 Markdown；`PEN_ALLOW_ROOTS` 给将来的 vault；commit 失败不再双写 |
| v0.1.2 | 用户点「新开会话」换 `session_id`，换框选不断上下文 |
| v0.1.3 | 上下文用量、等待 API 时的状态行 |
| v0.1.4 | 气泡是 Markdown 容器（LaTeX + Mermaid）——**插件里不要再打一份**，改走 Obsidian 自带的 `MarkdownRenderer` |

仓库里**仍然没有** `obsidian/`。CORS 白名单仍只有 Vite 的 5173 / 4173。

### 还缺（按切片）

**O-1 — 才能在库里点读（下一件该做的）**

1. 本仓新建 `obsidian/`：esbuild + TypeScript，打出 `manifest.json` / `main.js` / `styles.css`。
2. 右侧 `ItemView`：芯片、SSE、写回确认。诊断可以第二片叶子，可后置。
3. **选区改走 CM6**（`editor.getSelection()` + 行号）。`web/src/reader/` 的 `data-source-line` 是给浏览器阅读器用的，进库扔掉。
4. sidecar CORS 加上 Obsidian 桌面 origin（常见 `app://obsidian.md`，第一轮抓包确认）。SSE 必须用 `fetch`；`requestUrl` 不能流。
5. 设置页只放 sidecar URL、当前笔记是否已登记。**不要在插件设置里存 API key。**
6. 当前笔记 `POST /v1/handbooks/import`；vault 绝对路径靠已有的 `PEN_ALLOW_ROOTS`。`.pen/` 默认放库外（或 `~/.socrates-pen`），避免 Sync / 库 git 把轨迹和会话 sync 走。
7. `web/` Vite 演示原样留下。Chrome 验收继续打 5173 + 8765。

**O-2 — 像 Obsidian**

- 气泡 / 预览走 `MarkdownRenderer`，插件内不捆绑 katex、mermaid。
- `saveData` 按笔记路径记 `session_id`（替换 `localStorage['pen-session:…']`）。
- apply 之后主动刷新打开的叶子。

**进库写回之前最好先做（否则会从偶发变成默认）**

- Q3 的 stale-line：Obsidian 用户几乎一定会在 propose 和 apply 之间改笔记。
- 叶子有未保存缓冲时，sidecar 改磁盘会和 CM6 打架。apply 前要求叶子干净，或明确「这段时间别改」。

**不是插件门槛、可以继续欠着**

- Q2 掌握度状态机。若把现有诊断舱原样搬进去，必须写明「数的是问了几遍」。
- 按次撤销、50 轮墙钟。
- 社区商店、移动端、账号、向量检索。

## 要不要新开一个 repo？

**现在不要。** 第一版就开在 `Socrates-agent`，与 `web/`、`pen/` 并列加 `obsidian/`。

| 现在就拆仓 | 本仓加 `obsidian/` |
|---|---|
| `types` / SSE 解析立刻双份，改 `/v1` 漏一边 | 第二个客户端，契约只有一份 |
| 社区审核员先看到一大坨 Python + `.env` | 本阶段本就不送审 |
| 搬家成本现在就付 | 真要上架再抽，或用本仓打 Release 附件 |

官方「一个 GitHub 仓库」是**上社区目录、Release 挂三件套**时的习惯，不是开工条件。本地开发：把构建产物拷进 `Vault/.obsidian/plugins/socrates-pen/` 即可。

以后若上架，再二选一：继续 monorepo 发 Release，或把 `obsidian/` 抽成只含插件源码的仓。现在抽是给自己加搬家。

## 硬约束（从本产品带进插件）

- 默认 DeepSeek（`deepseek-v4-flash`）。钥匙只在 sidecar `.env`。
- 写回改的是磁盘上的真笔记；sidecar 写完后靠 Obsidian 文件监视器 reload，不是第一版就在插件里重写 `insert.py`。
- 换框选不断模型上下文；要切断就点「新开会话」（v0.1.2）。
- search 未开放就说未开放；不做账号 / Anki / 分数 / 向量检索。
- `.pen/` 隐私：轨迹和完整 `messages` 不出会被 Sync 的库目录。

---

## 建议的开工顺序（批准 O-1 之后才写代码）

1. 写并执行 O-1：本仓 `obsidian/` + CORS + `PEN_ALLOW_ROOTS` 指向测试库。出口：Live Preview 框选 → socratic → explain_zero → propose（先不 apply 真笔记）。
2. O-2：原生渲染 + apply 后刷新叶子。
3. 进真实写回前补 stale-line / 脏缓冲。

`web/` 与现有 pytest 全程保持可跑。
