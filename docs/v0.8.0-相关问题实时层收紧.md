# v0.8.0 — 相关问题实时层收紧

> 双层机制（v0.8.x）的第一步。这一版**零新增 LLM 调用**，只改 prompt 和过滤，单独发就修掉两个用户能看见的 bug。日期：2026-08-20。

## 为什么

侧栏底部的「相关问题」水平配不上这本书——它纠缠在「`echo` 后面加不加引号」上，而读者自己打字问的是「messages 每轮都整本读，任务长了不就把上下文撑爆了吗」。**工具提的问题比用户自己提的低一个档次。**

从 408 个落盘会话挖出 879 条历史生成（去重 47 条），根因有五条，这一版治其中三条：

1. **搭车产出，零判据。** `SYSTEM_PROMPT` 末尾对它的全部要求就是「- 下一问 1 / - 下一问 2」加一句「不要重复固定芯片的文案」。
2. **prompt 把「局部」写死了。**「动态建议必须是下一问」天然指向"顺着这段再挖一层"。
3. **目录被砍掉尾部。** `toc_lines[:80]`，而这本书实测 **87 条**——砍掉的正好是 Capstone 和附录，跨关问题的必需品。

另两条（邻域喂出局部题、好问题不落盘）留给 v0.8.1 / v0.8.2。

## 两个可见 bug

**占位符被当成芯片渲染。** 历史里有字面的「下一问 1」「下一问 2」「...」变成了按钮——模型把 prompt 的占位符原样抄出，前端照单全收。病根是示范文本本身长得像可填的空槽。

**复读用户原话。** 「messages 每轮都整本读，任务长了不就把上下文撑爆了吗？」这条**逐字**就是读者 08-18 自己打进去的话，模型把它吐回来当"下一问"。

## 改什么

### `pen/session.py`

`SYSTEM_PROMPT` 末段整段替换。三处改动：

- **拿掉 `下一问 1/2`**，换成两句具体成型、明显不切题的示范。模型抄一个成型句子的心理阻力远大于抄空槽；真抄了也能被 `PROMPT_EXAMPLE_LINES` 精确命中丢弃。
- **明说「恰好两行」**，配合 `chips[:2]`，给 v0.8.2 的深层芯片腾位置。
- **加一条负面指令**直接对准局部语法。

`REPLY_IN_ENGLISH` 不动——它说的是「Keep the block and its bullet format exactly as specified above」，仍然成立，`test_i18n.py` 的 `en.startswith(zh)` 也仍然成立。

`PenSession` 加两个字段，**只由请求线程写**（v0.8.1 的后台线程绝不碰 `PenSession`）：

- `last_chips: list[dict]` —— 本轮 quick 芯片，刷新不丢
- `turns: int` —— 轮次计数，给 v0.8.1 的冷却和 `born_round` 用

### `pen/tutor.py`

新增 `normalize_qkey()` 与 `looks_like_placeholder()`，`parse_dynamic_chips()` 硬化：

| 规则 | 动作 |
| --- | --- |
| `^(下一问\|next question\|问题)\s*\d*$` 或 `^[.…]+$` | 丢弃 |
| `^(下一问\|next question)\s*\d*\s*[:：]` | **剥前缀保留后半句** |
| 纯导航祈使句（`带我读`/`接着往下读`/`直接去`/`翻到`…） | 丢弃 |
| 无任何疑问标记 | 丢弃 |
| 与 `FIXED_CHIPS` 文案 bigram Jaccard ≥ 0.55 | 丢弃 |
| 与本轮 `user_text` bigram Jaccard ≥ 0.65 | 丢弃 |
| 与已抛过的撞车 / 相互重复 | 丢弃 |
| 写回运维类（`写回`/`校对`/`替换成`/`占位`/`行号`） | 丢弃 |
| 长度带 | 丢弃 |

返回值从 `list[str]` 升级为 `list[dict]`，截到 **2** 条。

**剥前缀而不是整条丢**很重要：「下一问 1：第三拍那五个例子，哪几个能挪来给第一、二拍当练习？」剥掉前缀后是一条好问题。

**踩过的坑**：第一版规则把「`第[一二三四五六七八九十]+拍` 开头且无问号」判为导航，误伤了「第五拍 Q2 的 heredoc 引号题怎么解」。收紧后只挡确定无疑的几类，在 47 条真实历史上零误伤。

`build_user_packet` 两处：`toc_lines[:80]` → 按字符预算 `TOC_CHARS = 4500` 截（实测全量 87 条只要 3647 字符，书再厚也不会失控）；新增 `[已经抛过的追问]` 段（keyword 参数 `asked=()`，默认空，不破坏现有调用）。

### `pen/app.py`

`gen()` 的 finally 里 `sess.turns += 1` 并存 `last_chips`；`_public_session()` 包一层，为 v0.8.1 拼接深问题预留位置。

`_finish_text` 同时发 `dynamic_chips`（`list[str]`，只放 quick）与 `dyn_chips`（富格式）—— `web/src/pen/PenPanel.tsx` 还在吃 `string[]`，不能破坏它。

### 前端

`types.ts` 加 `DynChip`；`PenView.dyn` 从 `string[]` 升级为 `DynChip[]`，`?? ` 回落旧格式（sidecar 与插件可能版本错配）；`adopt()` 从 `sess.dyn_chips` 恢复而不是清空。

## 验收

- 黄金集单测：2 条占位符必挡、4 条 `echo`/引号系必挡、**4 条好例必过**（防误杀比防漏更重要）
- `assert "下一问" not in SYSTEM_PROMPT` —— 最便宜的看门狗，以后谁写回去 pytest 立刻红
- `pytest` 全绿；`npm run build` 全绿
