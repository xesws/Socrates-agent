# v0.8.5 — 补齐 v0.8.4 列出的欠账

> v0.8.4 结尾诚实列了四条没做的，这一版全部补上，并且第一次在真实 Obsidian 环境下走完整链路。日期：2026-08-20。

## 四条欠账

### 1. 跨教材只能停在标题层

`_read_excerpts` 只读 `job.original_path`，所以书架上别的教材模型只看得到标题和大纲，永远读不到正文。读者的原话是「结合 working directory 下的其他教材」——停在标题层等于半个功能。

改：`need_read` 支持 `handbook_id` 字段。给了就去书架上查那本的路径，**必须是已登记且落在允许根内**的（跟 `shelf_digest` 同一道闸），否则忽略。总读取次数仍是 2 段的硬上限，跨不跨书都一样。

### 2. 配额耗尽时界面零信号

`budget` 服务端一直在返回，`types.ts` 也声明了，前端从不显示。读者看到的是「深题突然不再出现了」，没有任何解释。

改：`/v1/health` 带上探索配额（`used / max / window`），设置页的深挖开关下面显示「本小时已用 N/40」。放 health 而不是 inbox，是因为设置页手里没有 session_id。

### 3. 读者选的是「每小时 40 次」，实现成了「每天 40 次」

严了 24 倍。真实用量下都够，但这是明确的偏差。改成按小时窗口计数（`{"hour": "2026-08-20T05", "count": N}`），跨小时自动归零。

### 4. `_footprint` 只用锚点标题

轨迹里每条都存着 `user_text[:240]`，一个字都没用上。读者说的「user log」被降级成了「读过哪几道题的标题」。而且真实数据里 `最近读过` 经去重后会塌成一条——连续追问同一处时这行等于没有信息。

改：足迹里带上读者最近**自己打字问过的话**（最多 6 条），这比锚点标题信息量大得多。

## 真实环境验证

前四版全部只在 TestClient 和 node 复刻里验证过。这一版起了**真 sidecar**（uvicorn），
配真 LLM、真手册、真轨迹（189 条），框选 Level 6「Claude Code 的四档权限」，
问「这几档权限的分法，我们照搬了多少？」。

**实时层**（搭主回复的车，零额外调用，25 秒）：

> 那「完全同构」到底抄走了什么——是四档的答案，还是「按风险分级」这道题的解法？
> 少一档 acceptEdits，多出来的审批流量是不是全压到 Level 5 那条 approve 链上了，代价是什么？

v0.8.0 收紧 prompt 之后，连搭车产出的都已经不是「echo 加不加引号」那个档次了。

**深层**（独立调用，138 秒）：

> ◆ 模型用 sed 改写文件时，这台机器分得清它是编辑还是命令吗？
>   └ 师傅说白名单加危险检测顶了 acceptEdits 的岗，但那套组合是按命令内容切的，
>     Claude Code 是按操作类型切的——sed 正好是两把尺子

它指出了两种权限模型的**维度不匹配**，并且用 `sed` 这个具体命令把矛盾逼了出来。
这正是读者举例时想要的「我们和它有什么不同」。

链路其余部分同时确认：配额显示「会话 1/8 · 本小时 2/40」；关掉侧栏再打开时深题
排在最前、两条实时题也都在。

**等了 138 秒**——这也再次印证 v0.8.4 把轮询预算从 90 秒调到 5 分钟是必须的，
90 秒会正好错过。

### Chrome 渲染真实 styles.css

顺手发现两个只有真渲染才看得见的问题：

1. **300px 窄侧栏下深题落在滚动区外**。三个固定芯片就吃满了 6.4em，深题「排在最前」
   仍然在它们之后，实测完全不可见——等于没抛。改成新深题到达时 `scrollIntoView`。
2. **v0.8.0 加的芯片区放宽从来没生效过**。那两个 `@container` 块写在 `.sp-chips`
   主规则**前面**，同特异性下被后面的 `max-height: 6.4em` 覆盖了，白写了四个版本。
   挪到主规则之后，460px 涨到 9em、700px 涨到 12em，深题这才完整可见。

新增 `scripts/check-css.mjs` 看住三条真踩过的坑：零硬编码色值、`@container` 必须
写在主规则之后、每个 keyframes 都要被 `prefers-reduced-motion` 关掉。已接进
`npm test` 与 `npm run build`，并在一份「故意把断点挪回前面」的副本上确认它真会红。
