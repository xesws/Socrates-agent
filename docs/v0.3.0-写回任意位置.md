# v0.3.0 — 写回位置：默认跟选区，其余任意指定

> 模型仍然不准碰行号。默认 `plan_insert` 跟框选；确认前用户可改成任意行 / 光标 / 任意标题 / 任意 Q / 替换节或行范围。改目标走 `retarget`，不重打 LLM。日期：2026-08-20。

## 原语

- 插入：`insert_after_line`（1-based，该行之后）。
- 替换：`replace_start`–`replace_end` 闭区间；仅此模式允许缩短原文。
- 标题/Q/选区/光标都编译成上面两种。

## API

- `GET /v1/handbooks/{id}/outline` — 当前文件所有 ATX 标题 + `**Q**`。
- `POST /v1/writeback/retarget` — `proposal_id` + 目标，重算 plan/diff。
