# v0.14.0 — 首次公开发布

> 日期：2026-08-21。插件 semver 仍是 0.12.13（GitHub Release tag 必须等于 manifest）。

## 做什么

1. sidecar 可 `pip install git+https://github.com/xesws/socrates-pen.git` 再 `python -m pen`
2. 公开仓打 GitHub Release `0.12.13`，挂 `main.js` / `manifest.json` / `styles.css`
3. 提交 community.obsidian.md（若需登录则停在登录墙）

实验室仓不公开。手册、web、live 评测不进公开仓。

## sidecar 为外人能起必须改

- 没有默认手册时 `ensure_default()` 空操作
- pip 安装后数据目录默认 `~/.socrates-pen`，不要写进 site-packages
