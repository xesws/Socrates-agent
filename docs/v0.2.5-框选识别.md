# v0.2.5 — 侧栏「用当前选区」要认到笔记里划的字

> 对照 CLI 真机：点侧栏后 `getActiveViewOfType(MarkdownView)` 为 null，但 CM6 里选区还在。日期：2026-08-20。
> 性质：bug fix。加载已过；框选登记过不了。

## 现象

手册里划了一大段，点右侧「用当前选区」，提示没选够字。选区其实有，插件没去对的叶子上读。

## 原因

`readEditorPick` 只问**当前活动** `MarkdownView`。点侧栏按钮（或命令先 `activateView`）之后，活动叶子是 `socrates-pen-view`，活动 Markdown 变成 null，直接返回空。

阅读模式更糟：划的是预览 DOM，`editor.getSelection()` 本来就是空的；再一点按钮，`window.getSelection()` 也塌。

CM6 源码/实时预览里，失焦后 `editor.getSelection()` **还在**——只要去扫所有 `markdown` 叶子，不要只问活动视图。

## 改什么

- 扫全部 Markdown 叶子的 CM6 选区，不依赖活动视图。
- 阅读模式：选区在预览 DOM 里就认 `window.getSelection()`，行号按原文定位。
- `selectionchange` / `mouseup` 缓存上次有效选区；按钮 `pointerdown` + `preventDefault`，避免焦点把 DOM 选区清掉。
- 命令「用当前选区提问」：**先**取选区，**再**打开侧栏。

不改 sidecar，不 apply，不升对话协议。

## 验收

- 源码/实时预览：划一段 ≥4 字，点侧栏「用当前选区」，面板出现摘录。
- 阅读模式：同样能登记（行号按原文匹配，允许近似）。
- 失败：没划字就点，提示没读到选区，不拿旧文件瞎 import。
