# v0.2.8 — 新开会话要清掉上一场的选区

> 用户体验：已有 session 时点「新开会话」，顶上摘录还是上一场划的那段。日期：2026-08-20。
> 性质：插件 bug fix。不改 sidecar。

## 错在哪

`newSession` 已经 `POST /v1/sessions` 换 id、`adopt` 清空气泡，但 `this.quote` / `startLine` / `endLine` 和插件里的 `lastPick` 都不动。之后不划字也能继续拿旧选区发问；点「用当前选区」也会被缓存选区填回去。

网页文案曾写「框选还在」。Obsidian 侧按这次体验：**新场不带旧选区**。

## 改什么

点「新开会话」并确认后：

- 仍换 `session_id`，笔记绑定指到新场（避免下次框选 GET 回旧气泡）。
- 清 `quote`、行号、`lastPick`。
- 确认文案写明记忆和选区都会丢掉。
- 再问必须重新划一段并点「用当前选区」。

手册登记（`handbookId` / `capturedPath`）留下，同一篇笔记不用重新 import。
