# v0.1.4 — 每条对话框都是一个 Markdown 容器

> 点读笔 user / assistant / tool 气泡统一走 Markdown。接 KaTeX（`$` / `$$` / `\(` `\[`）和已有 Mermaid。日期：2026-08-18。

## 要点

- 共享 `markdown.ts`：`katex` + `markdown-it-texmath`；手册正文同样能渲染公式。
- 用户/工具 `html: false`；助手/手册 `html: true`。
- Mermaid 在气泡里防抖 200ms，避免每个 token 重画。
- ```text``` 里的 `$ echo $0` 不得变成公式。
