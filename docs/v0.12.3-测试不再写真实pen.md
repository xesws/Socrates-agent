# v0.12.3 — 测试不再写读者真实的 `.pen`

> 读者：「日志最多保存最近 7 天的会话吧，每次启动插件的时候都要自动清理一下，
> 不然用户的电脑就直接爆炸了……对的，就是这三件事，都要做：
> 1. 内存淘汰 2. 修复测试污染 3. 会话按时间清理」
> 日期：2026-08-21。

三件事里**先做这一件**，不然后面两件的验证数据全是脏的：
清理逻辑写完之后，`.pen/sessions/` 里到底剩几个文件，得能当证据用。

## 病灶

跑一次 `pytest` 会往读者真实的 `.pen/sessions/` 里写 **16 个**会话文件
（`test_app.py` 15 个 + `test_i18n.py` 1 个，指纹逐个对上）。

实测：跑之前 3389 个，跑一次之后 3405 个。这些文件和读者自己划词产生的会话
长得一模一样，事后谁也分不出哪个是测试拉的屎。

而且这不只是脏——它还在**给测试喂假的前提**：`test_tutor.py` 里有四条
直接 `libraries.load_index("swe-agent-v2")`，从来没自己建过默认手册。
它们能绿，纯粹是因为同一次 run 里 `test_app.py` 的 `TestClient(app)` 先跑过
一遍 lifespan，把 `swe-agent-v2` 写进了真实 `.pen`。**干净 checkout 上这四条会红。**

## 做法：`conftest.py` 一个 autouse fixture

四个名字就是全部（穷举验证过）：

```
config.PEN_DIR · config.LIBRARIES_DIR · libraries.LIBRARIES_DIR · snapshots.LIBRARIES_DIR
```

其余路径——`session.sessions_dir()` / `trajectory` / `proposals` /
`probe_store.probes_dir()` / `_quota_path()` / `app` 里那个 `/v1/usage` 的统计——
全是 `config.PEN_DIR / ...` **每次现算**，patch 根就够了。
只有 `libraries` 和 `snapshots` 写的是 `from pen.config import LIBRARIES_DIR`，
import 时就冻成了副本，得单独补两刀。

## 三个坑，两个是真踩上的

**① 一个目录都不许建。** `test_app.py` / `test_libraries.py` /
`test_snapshots.py` 里约 35 处是**裸 `lib.mkdir()`**（没有 `exist_ok`）。
fixture 里手滑加一句 `lib_dir.mkdir()`，实测 `test_pen_home_moves_pen_dir`
当场 `FileExistsError`。目录交给 `ensure_pen_dirs()` 懒建。

**② 绝不能 patch `config.REPO_ROOT`。** `sandbox.assert_handbook_path` 靠它
放行默认手册；patch 掉约 45 个测试会集体变红。所以 fixture 只搬 `.pen`，
不搬仓库根——`DEFAULT_HANDBOOK` 仍指向真实的那本手册（只读，不会被写）。

**③ `test_i18n.py:77` 用的是裸 `TestClient(app)`**（不跑 lifespan），
但它下一行已经手动 `ensure_default()`，隔离之后照样能跑。

## 顺手修掉的一处「靠污染才绿」

`test_tutor.py` 那四条各加一句 `libraries.ensure_default()`
（`register` → `build_index` 只要 0.03 秒）。现在它们自给自足，
不再依赖别的测试先跑过。

## 跨测试残留的模块级状态也一起清

`library_scan._CACHE`（TTL 60 秒，上一个测试写的文件会被下一个读到旧内容）、
`app._proposals`、`session.STORE._items` / `._locks`、`probe._inflight`。

现有测试里已经有十几处在手动 `library_scan._CACHE.clear()`——收进 autouse
之后不再靠每个作者记得写。`STORE` 那两个字典尤其必须清：临时 `.pen` 换了，
内存里还留着上一个测试的会话对象，等于把隔离绕过去了。

## 验收

**唯一算数的那条**：跑 `pytest` 前后 `ls .pen/sessions | wc -l` 不变
（3405 → 3405），且 `find .pen -newermt '-2 minutes'` 一个文件都没有。

守门的两条新测试在 `test_config.py`：
- `test_tests_never_write_the_real_pen_dir` — 四个名字逐个断言不指向真实 `.pen`，
  外加「`DEFAULT_HANDBOOK` 还读得到」（防止有人图省事把 `REPO_ROOT` 也 patch 了）
- `test_isolated_pen_dir_is_not_pre_created` — 守住「一个目录都不许建」

突变表加了三行（`58 项，全部会红`）：去掉 `PEN_DIR` 那刀、去掉
`libraries.LIBRARIES_DIR` 那刀、在 fixture 里抢先 mkdir——三种破坏各自会红。

`425 passed`（423 + 2 条新的）。
