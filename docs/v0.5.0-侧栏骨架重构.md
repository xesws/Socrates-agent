# v0.5.0 — 侧栏骨架重构

> 顶部栏一个容器装了所有东西。拆成五层，并把全部文案收进词表。日期：2026-08-20。

## 新骨架

```
.socrates-pen
├── .sp-brand   品牌条    flex:0 0 auto      状态点 + 点读笔 + 健康行 + 三个图标按钮
├── .sp-alert   错误条    flex:0 5 auto      有界，自己滚
├── .sp-log     对话区    flex:1 0 0         唯一主滚动区，min-height:4em
├── .sp-panel   审批面板  flex:0 1000 auto   第一个让位，自己滚
└── .sp-dock    底座      flex:0 1 auto      贴底
     ├── .sp-quote   flex:0 100 auto
     ├── .sp-chips   flex:0 10 auto   有界，自己滚
     ├── .sp-status  flex:0 0 auto
     └── .sp-form    flex:0 0 auto    永不压缩
```

真正保证布局不塌的**不是那些 max-height，是 flex-shrink 的权重阶梯**——权重乘以 base size，差两个数量级就等于严格优先级。让位顺序：面板 → 引文 → 芯片；输入行永远在，对话区永远至少 4em。即使某个主题让百分比无法解析，这个保证依然成立。

## 元素句柄用一个 bag

```ts
private els: Els | null = null;
async onClose(): Promise<void> { this.els = null; }
```

拆成十几个字段后漏掉任何一个，重开面板就会往已脱离文档的节点上写——**不报错**，只表现为「面板一片空白」。用类型系统消灭它，不靠记性。每个 paint 函数开头统一 `const e = this.els; if (!e) return;`。

`renderShell()` 只在 `onOpen` 跑一次，所有元素和事件监听的生命周期等于视图本身。`paintBar()` 降级成扇出壳，既有的 20 个调用点一行没改。

## 顺带修的

- **输入框不再被销毁**。之前每次 `paintBar()` 都 `empty()` 重建，焦点和未提交的半句话都会丢。现在只改 `.disabled`。
- **Enter 发送**，并挡住 `isComposing`——中文输入法里回车是确认候选词，不是发送。
- **命令名去掉「点读笔：」前缀**。Obsidian 注册时已自动加 `Socrates Pen: `，命令面板里一直显示成「Socrates Pen: 点读笔：打开面板」。id 没动，用户已绑的快捷键不受影响。
- **芯片签名缓存**：内容没变时只翻 `disabled`，不重建按钮。
- 健康行退居品牌条，单行省略，全文进 tooltip；用量与状态共用底座一行，底座高度不会因状态出现/消失而跳。
- 审批 diff 分「原文 / 换成」两块，红蓝左边框区分。

## 文案全部收进词表

新增 `src/i18n/{zh.ts, index.ts}`。`zh.ts` 是唯一允许写用户可见中文字面量的地方，**不加 `as const`**（加了之后 `typeof zh` 全是字面量类型，将来的 `const en: Dict` 永远无法满足）。静态文案裸字符串，带参的写箭头函数。

`phases` 的键对齐后端 `pen/tutor.py` 下发的 `ev.phase`，`phaseText()` 命中就本地化、没命中就照抄后端 text——后端将来新增 phase 不会让状态行变空白。以前前端完全无视 `phase`，直接用 `ev.text`。

这样 v0.7.0 做中英切换时只是加一张数据表，而不是把渲染代码再梳一遍。

## 实测（审批 + 9 芯片 + 错误条同时出现的最坏场景）

| 侧栏 | 对话区最小 | 输入行可点 | 审批按钮可点 | 横向滚动 |
| --- | ---: | --- | --- | --- |
| 300×700 | 68px | ✅ | ✅ | 无 |
| 400×850 | 215px | ✅ | ✅ | 无 |
| 500×1000 | 365px | ✅ | ✅ | 无 |
| 700×1200 | 565px | ✅ | ✅ | 无 |

英文标签（比中文长约 70%）一并测过，不撑破横向。`styles.css` 保持零硬编码色值。

## 不做什么
