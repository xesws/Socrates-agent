# v0.4.1 — edit_file 的 read-first 硬闸

> 手册 Level 4 Q8：先 read 再 edit，靠 system / schema / 错误串三方「教」。那是因为合法捷径「刚 write 完、原文我清楚」不能锁死。点读笔不注册 `write_file`，写回还要认小标题——必须在审批层加硬闸。日期：2026-08-20。

## 闸

`permissions.read_first_block`：`edit_file` 的目标路径，必须在**更早一轮**已经成功 `read_file`。同一批 `[read_file, edit_file]` 也拦——参数是看见读结果之前定的。

未过闸：回填错误、不进审批、不写盘。错误串写明：下一轮单独 `edit_file`；`old_string` 去掉 `N\t`。

## 同时补

- `read_file` schema：返回 `N\t原文`，行号是坐标。
- `edit_file` schema：必须先成功 read 同一路径；纯原文，不要带行号。
- 会话记住本场已读路径，审批续跑仍认。
